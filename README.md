# Ashley Outlet - Digital Furniture Catalog & A4 Print Engine
ئەلبوومی ئۆنڵاین و فەرمیی مۆبلیاتی ئاشڵی ئاوتلێت (Ashley Outlet)

سیستەمێکی خێرا و مۆدێرن بە دیزاینی هاوشێوەی Windows 11 کە بە تایبەت بۆ ئایپاد/تەبلێتی فرۆشیارەکان و پرێنتی یەک لاپەڕەیی A4 دیزاین کراوە.

---

## تایبەتمەندییە سەرەکییەکان:
1. **پۆڕتی کارکردن:** `http://localhost:3008`
2. **شێوازی گرایدی مۆدێرن (Windows 11 Fluent):** کارتەکانی مۆدێل بە دیزاینی Acrylic/شووشەیی کاڵ، گۆشە خڕ و بێ قەرەباڵغی.
3. **پێکهاتەی داتاکان:** کەتەگۆری (Category) ➔ ناوی کۆمەڵە/سێت (Collection) ➔ مۆدێلەکان (Models).
4. **وردەکاری مۆدێل:** وێنە، ناو، کۆدی SKU، بڕی بەردەست (عدد / Stock)، نرخی کۆن بە هێڵ بەسەردا کێشراو، نرخی ئێستای ئاوتلێت بە گەورەیی، ڕێژەی داشکاندن، و تێبینی/قیاسات.
5. **سیستەمی پرێنتی A4 (A4 Print Engine):**
   * **پرێنتی یەک مۆدێل:** ڕێک لەسەر ١ لاپەڕەی تەواوی A4 بە شێوازی مۆدێرن فۆڕمی فرۆشتن ئامادە دەکات.
   * **پرێنتی کۆمەڵ:** دوگمەی "پرێنتی فلتەرکراوەکان" بۆ چاپکردنی هەموو ئەو مۆدێلانەی لە سێرچ یان فلتەردا دیاری کراون، هەر مۆدێلێک لەسەر ١ لاپەڕەی جیا.
6. **سێ زمان:** کوردی (سۆرانی)، عەرەبی (العربية)، ئینگلیزی (English) بە گۆڕینی ئۆتۆماتیکی ئاراستە (RTL / LTR).
7. **بەڕێوەبردنی ئەدمین و فرۆشیار:**
   * فرۆشیار هیچ وشەی نهێنی ناوێت و دەستبەجێ بەکاری دەهێنێت.
   * لە سەرەوە بەستەری بچووکی `Login / چوونەژوورەوە` هەیە.
   * وشەی نهێنی پیشگریمانەکراو (Default Admin Password): `ashley123` یان `admin`.
   * ئەدمین دەتوانێت کەتەگۆری، سێت، و مۆدێلی نوێ زیاد بکات، وێنە لە مۆبایل/ئایپاد یان کۆمپیوتەر بار بکات (Upload)، یان ڕاستەوخۆ دەستکاری (Edit) و سڕینەوە (Delete) بکات.

---

## چۆنیەتی خستنەکار (How to Run):
1. دووجار کلیک لەسەر فایلی `start.bat` بکە، یان لە تێرمیناڵدا بنووسە:
   ```bash
   node server/index.js
   ```
2. لە وێبگەڕدا (Chrome / Safari) ئەم ناونیشانە بکەرەوە:
   ```text
   http://localhost:3008
   ```
3. بۆ کردنەوە لەسەر ئایپاد یان مۆبایل لە هەمان وایفای (Wi-Fi):
   * لە جێگەی `localhost`، ئایپی کۆمپیوتەرەکەت بنووسە، وەک: `http://192.168.1.50:3008`

---

## چۆنیەتی گواستنەوە بۆ هۆستی جیهانی (Global Hosting):
پرۆژەکە تەواو خۆماڵییە (Standalone Node.js):
1. تەنها فۆڵدەری پرۆژەکە دابنێ لەسەر هەر هۆستێک کە پشتگیری Node.js بکات (وەک cPanel Node.js Selector, VPS, Render, Railway, هتد).
2. لە تێرمیناڵی هۆستەکە بنووسە `npm install`.
3. فەرمانی دەستپێکردن: `node server/index.js`.
